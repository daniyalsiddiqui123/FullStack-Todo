# Reusable Skills for Todo App

This project includes several reusable skills to help with common development tasks. These skills are designed to automate repetitive tasks and streamline your development workflow.

## Available Skills

### `sp.env-setup`
Sets up the development environment with all necessary dependencies.

```bash
sp.env-setup
```

### `sp.db-reset`
Resets the database to a clean state for development.

```bash
sp.db-reset
```

### `sp.dev-start`
Starts both the frontend and MCP server simultaneously for development.

```bash
sp.dev-start
```

### `sp.test-run`
Runs all tests for the project with coverage reporting.

```bash
sp.test-run
```

### `sp.build-prod`
Builds the project for production deployment.

```bash
sp.build-prod
```

### `sp.deploy-hf`
Prepares and deploys the MCP server to Hugging Face Spaces.

```bash
sp.deploy-hf
```

## How to Use

These skills can be executed using the Claude Code Skill tool. Simply type the command in the Claude interface, and it will execute the corresponding workflow.

Each skill automates a common development task, saving you time and reducing the chance of errors during routine operations.
